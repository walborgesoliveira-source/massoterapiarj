# OS para Cliente - Regras Atuais de Agendamento

**Data:** 01/06/2026  
**Projeto:** Massoterapia RJ - agendamento online  
**Tipo:** Resumo informativo para cliente

## Resumo

O sistema de agendamento online da Massoterapia RJ foi ajustado para exibir horários de forma mais fiel à agenda real da equipe.

As regras atuais consideram a escala das profissionais, a duração do serviço escolhido, os atendimentos já marcados e a antecedência mínima necessária para novos agendamentos.

## Regras principais

- O agendamento feito pelo site entra no sistema como **Aprovado**.
- O cliente só consegue agendar com no mínimo **70 minutos de antecedência**.
- Todos os cálculos usam o horário de Brasília: **America/Sao_Paulo**.
- Não existe intervalo obrigatório entre atendimentos.
- A profissional pode receber novo atendimento imediatamente após o término do serviço anterior, se ainda estiver dentro do horário de trabalho.
- O sistema considera a duração real do serviço escolhido.
- O cliente escolhe uma profissional disponível no horário.

## Dias com duas profissionais

Quando houver duas profissionais no mesmo período, a disponibilidade é controlada por profissional.

Isso significa que, se uma profissional estiver ocupada, a outra pode continuar disponível no mesmo horário.

Exemplo:

- Amanda e Fabíola estão disponíveis às 14:00.
- Um cliente agenda com Amanda às 14:00.
- Amanda fica ocupada durante o atendimento.
- Fabíola continua disponível para outro atendimento no mesmo horário.

O horário só fica indisponível quando todas as profissionais disponíveis para aquele período já estiverem ocupadas ou fora da escala.

## Funcionamento esperado

1. O cliente escolhe o serviço.
2. Seleciona a data desejada.
3. O sistema mostra apenas horários possíveis.
4. O cliente escolhe uma profissional disponível.
5. O sistema valida novamente a agenda antes de registrar.
6. O agendamento é salvo e acompanhado pela equipe.

## Resultado

O cliente passa a visualizar uma agenda mais clara e confiável, evitando conflitos de horário e permitindo melhor aproveitamento dos períodos em que há mais de uma profissional disponível.

## Observação

Caso o cliente não encontre o horário desejado ou precise de ajuda para agendar, a orientação é entrar em contato pelo WhatsApp oficial da Massoterapia RJ.
